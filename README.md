# Reinforcement Learning

An introduction to reinforcement learning in a Jupyter notebook (written in French), with
**OpenAI Gym** and **TensorFlow**.

## Contents

`course1.ipynb` covers:

- The building blocks of RL: agent, environment, state, action, reward
- Using OpenAI Gym environments (CartPole)
- Hard-coded deterministic policies
- Neural network policies
- Policy gradient methods (REINFORCE)

## Getting started

```bash
pip install gym tensorflow numpy matplotlib seaborn
jupyter lab course1.ipynb
```

For more advanced material (Markov decision processes, Q-learning, DQN, TF-Agents), see the
reinforcement learning chapter of my [DeepLearning](https://github.com/LuCarpentier83/DeepLearning) repository.
